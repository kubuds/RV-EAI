# 参考实现与示例工程

用于存放 RV-EAI 的参考实现代码：参考镜像构建脚本、可插拔点的适配示例、端到端演示工程等。

规划中的内容（按五个可插拔点组织）：

| 目录（建议） | 内容 |
| --- | --- |
| `plugs/body/` | 关节驱动与 BSP 适配示例（CAN-FD / FOC 参数下发） |
| `plugs/cerebellum/` | 实时域控制环示例（RT-Thread 任务 + 关节总线） |
| `plugs/brain/` | 本地推理示例（LLM / VLM / VLA 调用与量化配置） |
| `plugs/os/` | 发行版适配脚本与依赖清单 |
| `plugs/framework/` | FlagOS / llama.cpp / TileLang 三条路线的接入示例 |

## 规则

1. 每个示例必须能在**参考镜像**上复现，并附 `README.md` 说明：硬件、系统版本、命令、预期输出。
2. 实测数据（时延、吞吐、功耗）必须写清条件，与站点口径一致（厂商数据与自测数据分开）。
3. 第三方代码放入 `3rd-party/` 登记，或在子目录内单独放 LICENSE。

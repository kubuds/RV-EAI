# 白皮书与发布材料

用于存放**可公开**的白皮书、架构蓝图、发布说明等文档（PDF / Markdown）。

## 收录规则

1. 只放已确认可公开的版本；内部讨论稿、含未公开测试数据的版本不要放进来。
2. 文件名建议：`<主题>-<版本>-<日期>.pdf`，例如 `rv-eai-architecture-v1-20261025.pdf`。
3. 每份文档在站点的「来源与许可」页登记来源与许可证；若内容引用第三方图表，需在该文档内单独注明。
4. 打包/导出脚本放在仓库根的 `scripts/`，不要与本目录混放。
